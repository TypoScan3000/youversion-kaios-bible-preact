# Offline Bible Data

> For additional versions please open an issue and a YouVersion developer will follow up.

This contains the offline bundles for public domain bibles and daily verse schedules.

As of November 2025 the bible zips are currently not optimized. There are several ongoing experiments for size reduction, compression improvements, and removing un-needed data.
